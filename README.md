Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Overview

This project is a simple car dealer website. It has a landing and a search page.

### Landing Page

The landing page has a hero section with a search form. The search form has a make and year dropdown. The user can
select a make, and year from the dropdowns and click on the Next button to navigate to the results page.

### Results Page

Results page shows a list of cars based on the search criteria.
